Baixar o programa

Windows · versão — · —

Na primeira vez, o Windows vai desconfiar.
Aparece a tela azul "O Windows protegeu o seu computador". Clique em Mais informações e depois em Executar assim mesmo. Acontece com todo programa novo sem certificado pago; é só na primeira vez.

Como usar

  1. Dois cliques no arquivo baixado. Não tem instalação.
  2. No passo 1, conecte o ChatGPT e o Gemini — uma vez só.
  3. No passo 2, escolha a planilha (colunas SKU e LINK).
  4. Clique em COMEÇAR e deixe trabalhando.

O que o computador precisa ter

  • Windows e o Google Chrome instalado.
  • Mais nada: o programa é um arquivo só e não instala nada.

Atualizações

Quando sair uma versão nova, o próprio programa avisa ao abrir e atualiza com um clique. Não precisa voltar aqui.

Em caso de problema, mande o arquivo de detalhes que o programa indica no botão Ver detalhes.
